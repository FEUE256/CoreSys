CoreSys OS Edition

A visionary standalone operating system engineered by FÈUE

About

CoreSys OS Edition is a bold and independent operating system developed from scratch by FÈUE. Designed exclusively for new UEFI systems. The system now boots through a custom bootloader and enters protected mode without any BIOS support. This do not have any support for BIOS or EDK2 or 32 bit mode only 64 bit mode!

Legal

CoreSys is developed by FÈUE as a research operating system focused on low-level computing, system architecture, and experimental design. Due to the requirements introduced by California Assembly Bill 1043 (Digital Age Assurance Act), CoreSys currently does not implement the mandatory operating system age-signal interface required for distribution within the State of California, United States.

As a result, CoreSys is not intended for distribution, installation, or use within California. Users located in California should not download, install, or operate CoreSys until compliance mechanisms are implemented or regulatory requirements change.
