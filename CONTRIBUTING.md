# Contributing to CoreSys

Thank you for your interest in contributing to **CoreSys**.

CoreSys is a UEFI-based operating system written in C, and contributions of all sizes are welcome — including code, documentation, testing, debugging, reviews, and design discussions.

## Before You Start

Please make sure to:

- Read the project documentation.
- Check existing issues and pull requests before creating new ones.
- Follow the project coding style and naming conventions.
- Test changes before submitting.

## Ways to Contribute

You can contribute by:

- Implementing new features
- Fixing bugs
- Improving documentation
- Writing or expanding tests
- Optimizing performance
- Reviewing pull requests
- Reporting issues
